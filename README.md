## SOUL INVADERS（`invaders/`）

Undertale風の世界観で、片手で遊べるインベーダー＋RPG。`invaders/index.html` をブラウザで開くだけで遊べます（ビルド不要）。

### ぜったいのルール
1. **片手で遊べること** — 操作は「どこでもドラッグ（左右移動）」と「タップ」だけ。攻撃は自動。
2. **いつでも中断・再開できること** — 右上の II でポーズ。プレイ中は自動セーブされ、アプリを閉じてもタイトルの「つづきから」で戻れる。
   10分以上たってから戻ると「おかえり！」と少しHPが回復する。

### せってい
- タイトル右下：**やさしい モード**（たまが おそく、ダメージが すくない）
- ポーズ画面：**うごきの はやさ**（ゆっくり／ふつう／はやい）

### あそびかた
- 画面のどこでもドラッグ → ソウル（赤いハート）が左右に動く（指でソウルが隠れないよう相対移動）
- 敵を倒すと G と EXP。LV が上がると HP・ATK・DEF が上がる
- 上から「SHOP」や「たからばこ」もおりてくる。ふれると中に入れる（たからばこには たまに ミミックが…）
- みせでは「はなす」で ポコから ヒントや うわさが きける
- 下のコマンド：たたかう／アイテム／そうび／みのがす。メニューを開いている間はゲームが止まる
- **あおい こうげき**は動かなければ当たらない。**オレンジの こうげき**は動いていれば当たらない
- 5ウェーブごとにボス。HPが減ると「みのがして」と言ってくる。**みのがす**か、**たたかう**で とどめを刺すか選べる
  - みのがすと おくりもの、たおすと たくさんの EXP。どちらを選んだかは ゲームをまたいで おぼえられている

- みのがした ボスは そのあと てつだってくれる（ボーンズ＝ほねで こうげき／ショボン＝あめで かいふく／マネキ＝1かいだけ こうげきを ふせぐ）
- ウェーブ15の ボスの あと、それまでの えらびかたで **3しゅるいの エンディング** がある（そのあとも つづけられる）
- ときどき モンスターが おどっている ウェーブが ある。たたかう？ みのがす？
- エンディングを みたあと、ウェーブ20で かくしボスが…（ルートで かわる）
- タイトルの「きろく」で これまでの きろくが みられる

ミカンボシ（オレンジの こうげき）／タテガイコツ（たてで ガード）／ワープネコ（いれかわる）／クラゲール（たまを まく）／
どろぼうネズミ（おかねを ぬすむ）／ミミック／まよいゴースト（みのがせる）／わらにんぎょう（うちつづけると おこる）

ボス：ボーンズ（ほね・ビーム）／ショボン（あめ・かみなり・まっくら）／マネキ（さかさま・はねかえし）

### キーボード
← → 移動、↑ ↓ えらぶ、Z・Enter 決定、X・Esc もどる、1〜4 コマンド、P ポーズ、M おと（ぜんぶ → こうかおんだけ → けす）
