## SOUL INVADERS（`invaders/`）

Undertale風の世界観で、片手で遊べるインベーダーゲーム。`invaders/index.html` をブラウザで開くだけで遊べます（ビルド不要）。

- 画面のどこでもドラッグ → ソウル（赤いハート）が左右に動く（指でソウルが隠れないよう相対移動）
- 攻撃は自動
- 敵を倒すと G（おかね）と EXP が手に入る。LV が上がると HP・ATK・DEF が上がる
- 上から「SHOP（みせ）」や「たからばこ」もおりてくる。ふれると中に入れる
  - みせ：G でアイテムやそうびを買える
  - たからばこ：アイテム・そうび・G のどれかが手に入る
- 下のメニュー（アイテム／そうび／つよさ）はいつでも開ける。開いている間はゲームが止まる
- キーボード: ← → / A D で移動、↑ ↓ でえらぶ、Z・Enter で決定、X・Esc でもどる、C でメニュー、M で消音
