## SOUL INVADERS（`invaders/`）

ドット絵と「予想外の展開」を土台に、いろいろな RPG のしくみを片手シューティングに折り曲げたゲーム。
`invaders/index.html` をブラウザで開くだけで遊べます（ビルド不要）。
スマホでは「ホーム画面に追加」するとアプリのように全画面で遊べ、オフラインでも動きます。
アイデアの元にした 30 タイトルと設計は [`invaders/DESIGN.md`](invaders/DESIGN.md) にまとめています。

### ぜったいのルール
1. **片手で遊べること** — 操作は「どこでもドラッグ（左右移動）」と「タップ」だけ。攻撃は自動。
2. **いつでも中断・再開できること** — 右上の II でポーズ。自動セーブ＋買い物・装備・宝箱などの直後にも即セーブ。
   アプリを閉じてもタイトルからそのまま再開できる。10分以上たってから戻ると「おかえり！」と少し回復。

### モード
- **ぼうけん（ストーリー）** — 約 15 時間のボリューム（目安）
  - 8 つの **ちほう** ＋ エンディング後の「うらがわ」。各ちほうは **3 枚のえだわかれマップ**（ヌシ → ヌシ → ボス）
  - ノード：たたかい／つよい てき／みせ／たきび／？（ダイスイベント）／たから／ボス
  - **たきび**：やすむ（HP まんたん）・きたえる（ぶき +1）・なかまと おちゃかい。倒れるとここに戻る
  - 倒れると G の半分をその場所に落とす。もう一度そこをクリアすれば拾える
  - たたかいの後は **かご（ブーン）を 3 つから 1 つ**。そのちほうの間だけ強くなる
  - 8 体のボスを みのがすか たおすかで エンディングが変わる。真のエンディングの後は 2しゅうめ
- **むげん** — これまでの、どこまで行けるかのモード

### おもな しくみ
- **ぞくせい と よわてん**：ほのお／みず／かぜ／ひかり／やみ。よわてんは 1.5 倍。強い敵は **シールド** を削り切ると **BREAK**（3 秒止まって 2 倍ダメージ）
- **そざい と つくる**：魔物の素材を集めて、ポコの店で属性武器・防具を作る（15 種）
- **チップ**：容量の中で組み合わせる（HP表示、じしゃく、ためうち、とりかえし、カウンター…）。OS チップは外さないで
- **なかま**：みのがした ヌシや ゴーストが一緒に戦う。きずなランクで強くなる
- **てちょう**（マップで左下）：きょうの おねがい（毎日 3 つ）、そざい、**にわ**（現実の時間で育つ。中断中も育つ）
- **かする と ケツイ**：弾のすれすれを通るとケツイが溜まり、たたかうで ケツイ ブラスト
- **あおい／オレンジの こうげき**：あおは動くと当たる、オレンジは止まると当たる
- メタルふわりん（すぐ逃げる・経験値が多い）、ミミック、どろぼうネズミ、セーブポイント、まっくら／かぜ／おどりのウェーブ など

### せってい
- タイトル右下：**モード**（やさしい／ふつう／エンディング後に **ケツイ**）
- ポーズ画面：**うごきの はやさ**、**あそびかた**

### キーボード
← → 移動、↑ ↓ えらぶ、Z・Enter 決定、X・Esc もどる、1〜4 コマンド、P ポーズ、M おと（ぜんぶ → こうかおんだけ → けす）
