# ゲートボール1103準拠カードゲーム（仮）

遊戯王OCGのゲートボール「1103環境」（2011年3月1日施行の制限リスト、2011年8月31日までのカードプール）をベースにしたカードゲームの第1弾データ。
**ルール・カードの性能（数値と効果）・デッキ構成は参照元と同じにしてあり、カード名・テーマ名・文章は独自のもの。**

| ファイル | 内容 |
|---|---|
| [rules.md](rules.md) | ルール全文（マスタールール2相当、先攻ドローあり、EXモンスターゾーンなし） |
| [limit_list.md](limit_list.md) | 制限リスト（2011年3月リスト準拠）と、まだ収録していないカードの扱い |
| [cards.md](cards.md) | 収録カード191種の一覧（数値・効果） |
| [decklists.md](decklists.md) | 10デッキのレシピ（寒波亭の大会入賞レシピ。出典・順位つき） |
| [decks.md](decks.md) | 環境分析、各デッキの解説、相性表、使ったデータ |
| `data/cards.json` `data/decks.json` | 上記の機械可読データ（`ref` は開発用の参照元カード名） |
| `game/index.html` | 遊べるデュエル（ブラウザで開くだけ。効果・チェーン・フェイズはデュエルエンジンが自動処理。CPU対戦／2人対戦） |
| `game/` | ゲームのソース（`src/`）、エンジン用カードスクリプト（`scripts/`）、ビルド・テスト |
| `tools/` | 生成スクリプト一式 |

## データの作り方

- **制限リスト**：2011年3月1日施行のOCGリストを、YGOPro（Fluorohydride/ygopro）の2011年12月時点の `lflist.conf` から取り出した（`tools/lflist_2011_03_ocg.json`、134種）。
- **カードの数値**（レベル・属性・種族・攻守）：ProjectIgnis/BabelCDB の `cards.cdb` から自動で取得。
- **効果**：DB上の現行テキストではなく、**2011年当時（エラッタ前）の性能**で書き直した。例：「増え続ける甲虫」は1ターンの回数制限なし、「夜鴉 精鋭のゼフィ」は回数制限なし、「三眼の使い魔」は回数制限なし、「氷壁の龍ブリュンガル」はフィールドのどのカードでも戻せる。
- **ビルド時のチェック**：メイン40〜60枚、エクストラ15枚以下、制限枚数、融合・同調・重ねモンスターがエクストラ側にあること。

```sh
cd tools
curl -L -o cards.cdb https://raw.githubusercontent.com/ProjectIgnis/BabelCDB/master/cards.cdb
python3 build.py cards.cdb   # data/ と *.md を作り直す
```

## 注意点・未確定の部分

1. **デッキレシピ**：10デッキは寒波亭の資料室（note）と公式デッキDBに掲載された入賞レシピ。取得した元データは `recipes/raw/`（ブランチ `claude/gateball-recipes-raw`）。代行天使だけは入賞レシピの画像が判読しにくかったため、寒波亭が公式DBに登録した参考レシピ（入賞記録の記載なし）を使っている。TGガジェットは判読できなかった罠2枚を除いた43枚。
1-2. **環境分析**：「直近100大会のベスト8」の全集計はしていない。読めた範囲の大会結果とTier表を使った（詳細は [decks.md](decks.md) §1）。
2. **カードプールの境界**：一部のカード（重ねモンスターや後期のテーマカードなど）は、2011年8月31日までに発売されていたかを一次資料で確かめられていない。疑わしいものは採用を避けたが、各大会のカードプール規定と照らし合わせることを推奨。
3. **収録範囲**：10デッキ（大会入賞レシピ）に使う191種だけを移植した。参照元の全カードプールの移植は今後の作業（`limit_list.md` の開発用資料に、未収録の制限カードも載せてある）。
4. **公開前の確認**：`data/*.json` の `ref` 欄と `limit_list.md` の開発用資料には参照元のカード名が入っている。一般向けに公開する時は削除すること。

## ゲーム（自動処理デュエル）

- デュエルエンジンに **EDOPro のコア（ocgcore）** の WebAssembly 版（npm `ocgcore-wasm` 0.1.2、MIT）を使い、カードの効果は **ProjectIgnis/CardScripts** の Lua スクリプト（AGPL-3.0）で処理する。ADS → YGOPro → EDOPro と続く「スクリプトでカード効果を処理する」方式。
- ルールはエンジンの「マスタールール2」設定（先攻もドロー、フィールド魔法は場全体で1枚）。
- 2011年当時の性能に合わせて一部スクリプトを差し替えている（`game/scripts/PATCHES.md`）。
- CPUは簡単な評価で動く（強い手を読むAIではない）。
- `game/scripts/` は AGPL-3.0 のため、ゲームを公開・配布する場合はソースの公開などAGPLの条件に従うこと。

```sh
cd game
npm install
npm run build   # index.html を作る（約2MB、エンジンとデータを1ファイルに埋め込み）
npm test        # CPU同士で全組み合わせを対戦させ、決着まで進むかを確認
```
