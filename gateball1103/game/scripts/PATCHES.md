# スクリプトの出典と変更点

- 出典：[ProjectIgnis/CardScripts](https://github.com/ProjectIgnis/CardScripts) コミット `208b6b3`（2026-04-14）。ライセンスは AGPL-3.0（`COPYING`）。
- 使用しているのはルート直下の共通スクリプトと、本ゲーム収録カード148種（通常モンスター3種はスクリプトなし）の `official/c<コード>.lua`。
- `proc_unofficial.lua` はアニメ等の非公式カード用なので空ファイルに置き換えている。
