# 基本ルール（1103準拠）

遊戯王OCG「マスタールール2（2011年3月施行）」と、それを使うゲートボール1103環境の運用を、そのまま本ゲームのルールとして文章化したもの。
用語のうち召喚法・テーマ名だけは独自名に置き換えている（下表）。

| 本ゲームの用語 | 参照元の用語 |
|---|---|
| 調律（調律モンスター） | チューナー |
| 同調召喚／同調モンスター | シンクロ召喚／シンクロモンスター |
| 重ね召喚／重ねモンスター／重ね素材 | エクシーズ召喚／エクシーズモンスター／エクシーズ素材（ORU） |
| デュアル | デュアル（ジェミニ） |
| C〇〇（コード） | No.〇〇 |
| 『〇〇』 | 「〇〇」と名のついたカード（カテゴリ） |

---

## 1. デッキ構築

1. **メインデッキ** 40〜60枚。融合・同調・重ねモンスターは入れられない。
2. **エクストラデッキ** 0〜15枚。融合・同調・重ねモンスターのみ。
3. **サイドデッキ** 0〜15枚。マッチ中、各デュエルの間にメイン／エクストラと1枚ずつ交換できる（交換後も各デッキの枚数条件を守る）。
4. 同名カードはメイン・エクストラ・サイド合計で **3枚まで**。
5. **制限リスト**（[limit_list.md](limit_list.md)）に従う。禁止＝0枚、制限＝1枚、準制限＝2枚。
6. カードの効果は**2011年8月31日時点のテキスト（エラッタ前）**で扱う。本ゲームのカードテキストは既にその性能で書かれている。

## 2. デュエルの準備と勝敗

- 初期LP **8000**。デッキをシャッフルし、相手にもシャッフル／カットさせる。
- ジャンケン等で勝った方が先攻・後攻を選ぶ。2戦目以降は直前のデュエルの敗者が選ぶ。
- お互い **5枚** ドローして開始。
- 勝利条件：
  - 相手のLPを0にする（同時に0になれば引き分け）。
  - 相手がドローすべき時にデッキが0枚でドローできない。
  - カードの効果による特殊勝利。
- マッチは**3本勝負（2本先取）**。制限時間は大会ごとに定める。

## 3. フィールド

各プレイヤーは以下のゾーンを持つ。

| ゾーン | 数 | 内容 |
|---|---|---|
| モンスターゾーン | 5 | モンスターを表側攻撃・表側守備・裏側守備で置く |
| 魔法・罠ゾーン | 5 | 魔法・罠を表側（発動・永続）または裏側（セット）で置く |
| フィールドゾーン | 1 | フィールド魔法。**表側表示のフィールド魔法は場全体で1枚まで**：どちらかのプレイヤーが新たにフィールド魔法を発動すると、既に表側表示で存在するフィールド魔法（相手のものも含む）は破壊される |
| デッキ | — | 裏向き。順番を見たり変えたりできない |
| エクストラデッキ | — | 裏向き。自分は中身を確認できる |
| 墓地 | — | 表向き。お互いいつでも確認できる |
| 除外 | — | 原則表向き。ゲームから取り除かれたカード |

※ 本環境には「エクストラモンスターゾーン」「ペンデュラムゾーン」「リンク」は**存在しない**。エクストラデッキから出すモンスターも通常のモンスターゾーン5つに置く。

## 4. ターンの流れ

1. **ドローフェイズ**：ターンプレイヤーは1枚ドローする。**先攻1ターン目もドローする。**
2. **スタンバイフェイズ**：「スタンバイフェイズに」発動・適用する効果を処理する。
3. **メインフェイズ1**：召喚、魔法・罠のセット／発動、表示形式の変更、起動効果の発動などを行う。
4. **バトルフェイズ**：スタートステップ → バトルステップ → ダメージステップ → エンドステップ。**先攻1ターン目は攻撃できない。** バトルフェイズは行わなくてもよい。
5. **メインフェイズ2**：メインフェイズ1と同じことができる（通常召喚は1ターンに1回の合計）。
6. **エンドフェイズ**：「エンドフェイズに」の効果を処理する。手札が **7枚以上** なら6枚になるよう捨てる。

## 5. モンスター

### 5-1. 種類
- **通常モンスター**、**効果モンスター**、**融合モンスター**、**同調モンスター**、**重ねモンスター**、および特性として**調律**・**デュアル**を持つものがある。
- 属性：地・水・炎・風・光・闇。種族：戦士族・魔法使い族・天使族・悪魔族・アンデット族・機械族・水族・炎族・岩石族・鳥獣族・植物族・昆虫族・雷族・ドラゴン族・獣族・獣戦士族・恐竜族・魚族・海竜族・爬虫類族・サイキック族。
- 重ねモンスターは**レベルを持たず**、代わりに**ランク**を持つ。レベルを参照する効果・同調素材・レベル条件の対象にはならない。

### 5-2. 通常召喚・セット（1ターンに1回）
- レベル4以下：リリースなしで召喚／裏側守備でセット。
- レベル5・6：自分のモンスター1体をリリース（アドバンス召喚）。
- レベル7以上：2体リリース。
- 召喚は表側攻撃表示、セットは裏側守備表示。

### 5-3. 反転召喚・表示形式の変更
- 裏側守備のモンスターを表側攻撃表示にするのが**反転召喚**（メインフェイズ、回数制限なし）。
- 表示形式の変更は、各モンスターにつき1ターンに1度。**そのターンに召喚・特殊召喚・セットしたモンスター、そのターンに攻撃したモンスターは変更できない。**
- 裏側のモンスターが表になることを**リバース**という（戦闘で攻撃されて表になった場合も含む）。

### 5-4. 特殊召喚
- カードの効果による特殊召喚：チェーンに乗る効果として処理される。
- **召喚条件による特殊召喚**（例：「〜場合、このカードは手札から特殊召喚できる」）：チェーンに乗らず、他の行動として行う。メインフェイズで、ターンプレイヤーがチェーンの発生していない時に行える。回数制限なし（カードに記載がある場合を除く）。
- 融合・同調・重ねモンスターは、正規の方法（融合召喚・同調召喚・重ね召喚）でエクストラデッキから出た後でなければ、墓地・除外から特殊召喚（蘇生）できない。
- 「〜でしか特殊召喚できない」と書かれたモンスターは、正規の方法以外では一切特殊召喚できない（蘇生も不可）。「〜でのみエクストラデッキから特殊召喚できる」は、正規召喚後なら蘇生できる。

### 5-5. 融合召喚
- 「融合」系の魔法などの効果で、指定された融合素材を墓地へ送る（または効果に従い除外する）ことで、エクストラデッキから融合モンスターを特殊召喚する。

### 5-6. 同調召喚（シンクロ）
- 自分のメインフェイズに、自分フィールドの表側表示の **調律1体＋調律以外のモンスター1体以上** を墓地へ送り、それらの**レベルの合計と同じレベル**の同調モンスターをエクストラデッキから特殊召喚する。
- 素材の種類が指定されている場合はそれに従う（例：「戦士族調律」「『夜鴉』調律」）。
- チェーンに乗らない特殊召喚。召喚に対しては「召喚・特殊召喚を無効にする」効果で無効にされうる。

### 5-7. 重ね召喚（エクシーズ）
- 自分のメインフェイズに、自分フィールドの表側表示の **同じレベルのモンスター** を指定数重ね、そのレベルと同じランクの重ねモンスターをエクストラデッキから特殊召喚する。
- 重ねたモンスターは**重ね素材**としてその重ねモンスターの下に置かれ、フィールドのモンスターとしては扱わない。重ねモンスターがフィールドを離れたら重ね素材は墓地へ送られる。
- 重ね素材の「取り除き」は墓地へ送る扱い。
- **トークンは重ね素材にできない。**重ねモンスターは重ね素材・同調素材にできない（レベルを持たないため）。

### 5-8. トークン
- 効果で生成されるモンスター。フィールド以外へ移動する場合は消滅する（手札・デッキ・エクストラ・墓地・除外に行けない）。同調素材・リリースには使用できる。

## 6. 魔法・罠

| 種類 | 発動できるタイミング | スペルスピード |
|---|---|---|
| 通常魔法 | 自分のメインフェイズ、チェーン1として | 1 |
| 永続魔法 | 同上。発動後フィールドに残る | 1 |
| 装備魔法 | 同上。モンスター1体に装備 | 1 |
| フィールド魔法 | 同上。フィールドゾーンに置く | 1 |
| 速攻魔法 | 自分ターンならいつでも手札から。セットした場合は**セットしたターンの次のターン以降**、相手ターンでも発動可 | 2 |
| 通常罠／永続罠 | セットした**次のターン以降**、お互いのターンで発動可 | 2 |
| カウンター罠 | 同上 | 3 |

- 魔法・罠を手札から直接発動できるのは魔法のみ（速攻魔法の相手ターン発動・罠は要セット）。
- 例外として、カードに「手札から発動できる」と書かれた罠（例：「三羽鴉の逆襲」）はその条件下で手札から発動できる。

## 7. 効果の種類

- **起動効果**：自分のメインフェイズに宣言して発動（スペルスピード1）。
- **誘発効果**：特定の条件を満たした時に発動（スペルスピード1）。
- **誘発即時効果**：相手ターンでも、条件を満たせばチェーンして発動できる（スペルスピード2）。
- **永続効果**：表側表示で存在する限り適用され続ける。発動しない。
- **ルール効果**：召喚条件・素材制限など。

### 7-1. コストと効果
- 「〜して発動できる」「〜を払って」等、発動時に支払う部分は**コスト**。チェーンを組む前に払い、発動が無効になっても戻らない。

### 7-2. 対象をとる効果
- 「〜を対象として」と書かれた効果は発動時に対象を決める。処理時に対象が不適正（フィールドを離れた、裏側になった等）なら、その部分は処理されない。

### 7-3. 「時」と「場合」（タイミングを逃す）
- 「〜した**時**、〜できる」（任意の誘発効果）は、その条件の発生が処理の**最後**でない場合、**タイミングを逃して発動できない**。
  - 例：チェーン2で墓地へ送られたモンスターの「墓地へ送られた時に〜できる」は、チェーン1の処理が後に残っているため発動できない。
  - 例：コストとして墓地へ送られた後に別の処理がある場合も同様。
- 「〜した**場合**」の効果、および強制効果（「〜する」）はタイミングを逃さない。
- 本環境の多くのカードがこの区別に依存する（例：『魔窟』の「捨てられた場合」はタイミングを逃さない）。

## 8. チェーン

1. 効果・カードを発動したら、相手は（自分も）それに**チェーン**して発動できる。
2. チェーンに積めるのは、直前のカード以上のスペルスピードのもののみ（スペルスピード3にはスペルスピード3しか積めない）。
3. お互いにチェーンしなくなったら、**最後に発動したものから逆順に**処理する。
4. 同時に複数の誘発効果が発生した場合は、以下の順でチェーンを組む：ターンプレイヤーの強制効果 → 非ターンプレイヤーの強制効果 → ターンプレイヤーの任意効果 → 非ターンプレイヤーの任意効果。
5. **召喚・特殊召喚・反転召喚そのもの**はチェーンに乗らない。これに対しては「召喚を無効にする」カード（カウンター罠や「覇古竜ラグナレイジ」等）のみ対応できる。召喚に成功した後は、ターンプレイヤーが先に優先権を持つ。
6. 同名カードを同一チェーン上で複数回発動することは、カードに禁止の記載がなければ可能。

## 9. バトル

### 9-1. 攻撃
- バトルステップで、自分の表側攻撃表示モンスターで攻撃宣言する（各1回）。相手フィールドにモンスターがいなければ**直接攻撃**できる。
- 攻撃対象のモンスターが消える／増える等で相手のモンスターの数が変化した場合は**巻き戻し**が発生し、攻撃モンスターは攻撃対象を選び直す（攻撃しないことも選べる）。

### 9-2. ダメージステップ
1. 開始時 → 2. ダメージ計算前（裏側の守備モンスターはここでリバースする）→ 3. ダメージ計算時 → 4. ダメージ計算後 → 5. 終了時。
- ダメージステップ中に発動できるのは、**カウンター罠**と、**攻撃力・守備力を変化させる効果**、およびダメージステップで発動することが明記された効果のみ。

### 9-3. ダメージ計算
| 攻撃側 | 対象 | 結果 |
|---|---|---|
| 攻撃力 | 攻撃表示（攻撃力） | 低い方が破壊され、差分を低い方のプレイヤーが受ける。同値は両方破壊、ダメージなし（0同士なら破壊なし） |
| 攻撃力 | 守備表示（守備力） | 攻撃力が高ければ守備モンスターを破壊（ダメージなし）。低ければ攻撃側プレイヤーが差分ダメージ、破壊なし |
| 直接攻撃 | — | 攻撃力分のダメージ |
- **貫通**：守備表示モンスターを攻撃した場合に、攻撃力が守備力を超えた分の戦闘ダメージを与える。

## 10. その他の処理

- **ドロー以外で手札に加える**：「サーチ」「回収」等。
- **捨てる**：手札から墓地へ送ることのうち、効果やコストで「捨てる」と書かれたもの。
- **除外**：表向きで除外ゾーンへ。除外を参照する効果以外では再利用できない。
- **リリース**：コストとして墓地へ送ること（召喚のリリースも含む）。
- **破壊**：効果または戦闘による。「破壊されない」効果は破壊のみを防ぐ（除外・バウンス等は防げない）。
- **無効**：「発動を無効」はカード自体が発動しなかった扱い（コストは戻らない）。「効果を無効」は発動はした扱い。
- **デッキからのカード移動**：「雷獣王ボルガ」のような永続効果が適用中は、ドロー以外でデッキからカードを手札に加えられない（デッキから墓地へ送る・特殊召喚することはできる）。

## 11. 大会運用（ゲートボール1103準拠）

- カードプール：本ゲームで発行されたカード（参照元の2011年8月31日までのカードに相当）。
- 制限リスト：[limit_list.md](limit_list.md)（2011年3月1日施行リスト準拠）。
- 大会独自規定：参照元の大会では、プール外の一部カード（参照元「血の代償」相当）を独自に準制限とすることが多い。本ゲームで同等のカードを追加した場合はこれに倣う。
- 本ゲームのカードテキストに書かれた性能が最終的な裁定となる。裁定に迷う場合は参照元（当時のOCG裁定）を基準とする。
