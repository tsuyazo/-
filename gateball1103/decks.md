## 2. 環境の構造

1. **罠の質と量がそのまま強さになる環境**。「底なしの奈落」「天啓の警鐘」「天啓の審判」「大激流」「反射の聖壁」「次元の牢獄」「強制退去装置」がほぼ全デッキの共通パーツで、メインの3割前後が罠。
2. **特殊召喚の量で2つに分かれる**。
   - 少しだけ出して罠で守るデッキ：古竜ラグナレイジ（兎ラギア）、星使（代行天使）、勇士（HERO）、機巧（カラクリ）。
   - 大量展開するデッキ：瓦礫竜ハーモン（デブリ）、クイックハーモン、試作機ギア人形（TG）、武士団（六武衆）、夜鴉（BF）、魔窟（暗黒界）。
   - 前者は「増え続ける甲虫」「雷獣王ボルガ」「王政の圧制」「大熾天使アークリスタ」で後者を止めにいく。この噛み合いが環境の軸。
3. **ランク4の重ね召喚が全デッキの共通の出口**。「C39 希望の光騎士」が攻撃を止める壁兼打点になる。古竜は「覇古竜ラグナレイジ」で召喚・魔法・罠を無効にでき、罠デッキとして一番強い形。
4. **後攻の捲りは「虚無の大穴」「疾風の旋刃」「魔剣士ブレイズ」「勇士ゲイルウィング」**。制限カードを何枚引けるかで勝負が決まる面が大きい。
5. 先攻もドローできるので、先攻有利がかなり大きい。

## 3. 10デッキ解説

### ① 古竜ラグナレイジ（参照：兎ラギア）— Tier S
- **狙い**：「救援の野ウサギ」で同名の通常モンスター（恐竜）2体をデッキから出し、「覇古竜ラグナレイジ」（召喚・魔法・罠を1回無効）か「C39 希望の光騎士」を立てる。あとは罠で守る。
- **強み**：手札1枚で重ねモンスターが出る。メインは罠の多いパーミッション型で、「雷獣王ボルガ」「王政の圧制」「増え続ける甲虫」で展開デッキに強い。
- **弱み**：「野ウサギ」以外の初動が少ない。「底なしの奈落」「次元の牢獄」でラグナレイジを除去されやすい。
- **主な動き**：野ウサギ召喚 → 除外してサーベラス×2 → ラグナレイジを重ね召喚。

### ② 星使（参照：代行天使）— Tier S
- **狙い**：「秘星使テラ」→「創星使ウェヌス」→「光玉ルミナ」で数を並べ、「星使の主 ソル・マギステル」の破壊効果（「天上の聖庭」があれば1ターンに2回）で盤面を取る。墓地の天使族が4体になったら「大熾天使アークリスタ」で特殊召喚を止める。
- **強み**：ソル・マギステルの継続的な除去と、アークリスタのロックが強い。
- **弱み**：LPを払う動きが多く、バーンや大激流に弱い。墓地の天使族の数を調整する必要がある。
- **主な動き**（通常召喚は1ターンに1回なので、どちらか一方を召喚する）：
  - ウェヌスを召喚 → 500LPずつ払ってデッキからルミナを並べる → ウェヌスを除外してソル・マギステルを手札から特殊召喚。
  - 場にモンスターがいない時に「天界の大広間」で手札のウェヌスを特殊召喚 → テラを通常召喚してソル・マギステル（聖庭がある時）かウェヌスをサーチ。
  - テラを召喚した場合、サーチしたウェヌスはそのターンには召喚できない（次のターン以降、または大広間で出す）。

### ③ 勇士（参照：HERO／アライブHERO・ピュアHERO）— Tier A
- **狙い**：「緊急招集」「勇士再臨」でサーチし、「元素の勇士 ゲイルウィング」で魔法・罠を割る。「奇跡の融合」から「フロストゼロ」（離れると相手モンスター全破壊）や「シャドウレイ」を出す。
- **強み**：サーチが厚く安定する。罠ビートで、後攻の捲りも得意。
- **弱み**：単体の打点が低めで、「雷獣王ボルガ」にサーチを止められる。
- **主な動き**：勇士再臨（LP半分）→ ゲイルウィング特殊召喚、効果で勇士をサーチ → 2体目の勇士を召喚 → 奇跡の融合でフロストゼロ。勇士が並んだ状態でゲイルウィングを出せば、その数だけ伏せカードを割れる。

### ④ 試作機ギア人形（参照：TGガジェット）— Tier A
- **狙い**：ギア人形（紅→琥珀→翠→紅…）が1枚ごとにサーチしてくるので手札が減らない。そこに試作機（チューナー）を足し、レベル5〜8の同調召喚で「試作機ライブラリアン」のドローや「氷壁の龍ブリュンガル」の手札戻しにつなぐ。
- **強み**：手札が尽きにくく、罠が多いので長期戦に強い。（寒波亭では「TG代行天使」という混成型も準優勝している。）
- **弱み**：初動の打点が低い。「雷獣王ボルガ」でサーチを止められる。
- **主な動き**：相手の場だけにモンスターがいる時に、先にストライカーを手札から特殊召喚 → 紅を通常召喚して琥珀をサーチ → 紅（4）＋ストライカー（2）でレベル6同調（ブリュンガル）。紅を先に出すとストライカーの条件（自分の場にモンスターがいない）を満たせなくなる。

### ⑤ 瓦礫竜ハーモン（参照：デブリダンディ）— Tier A
- **狙い**：「瓦礫竜デブリス」「ハーモン・スクラップ」で墓地の植物を蘇生し、「綿毛の獅子花」のトークン、「育ちの球根」「胞子の調律花」の自己再生を絡めて同調召喚を連打する。「氷壁の龍トリスカル」「黒薔薇の魔竜」が決め手。
- **強み**：1ターンでの展開量と、トリスカルの3枚除外が非常に強い。
- **弱み**：「増え続ける甲虫」「雷獣王ボルガ」「王政の圧制」「大熾天使アークリスタ」に止められる。
- **主な動き**：「愚者の埋葬」や「ひとつと引き換えに」で綿毛の獅子花・育ちの球根を墓地へ → 綿毛トークン2体 → ハーモン・スクラップを通常召喚して墓地の球根を蘇生 → 同調召喚を連打。終焉の騎士とハーモン・スクラップはどちらも通常召喚なので、1ターンに使えるのは片方だけ。

### ⑥ クイックハーモン（参照：クイックジャンド/クイックダンディ）— Tier A
- **狙い**：「ハーモン・クイック」（手札1枚を墓地へ送って特殊召喚できるレベル5チューナー）で植物を墓地へ送りつつ同調召喚する。「位喰いの羽虫」でレベルを調整する。
- **強み**：「調律の儀」でデッキを掘れて初動が安定する。手札誘発（甲虫・ヴェール）を構えながら展開できる。
- **弱み**：ハーモン・クイックの素材制限があり、出せる同調モンスターが限られる。妨害への弱さはデブリ型と同じ。

### ⑦ 武士団（参照：六武衆）— Tier A
- **狙い**：「剛刃のキザシ」など手札から特殊召喚できるモンスターを並べ、「武士団の結束」でドロー、「武士団の門」でサーチ。「大将軍 蒼月」で魔法・罠を無効にする。
- **強み**：手札だけで展開できて爆発力がある。「勾玉の守護」で破壊効果を防げる。
- **弱み**：「虚無の大穴」「大激流」が刺さる。手札誘発・パーミッションへの耐性が低い。
- **主な動き**：カゲトキを召喚し、効果で手札の影武者を特殊召喚 → キザシを手札から特殊召喚 → 結束にカウンター2 → 影武者（2）＋カゲトキ（3）で蒼月を同調召喚。

### ⑧ 魔窟（参照：暗黒界）— Tier B（寒波亭で優勝あり）
- **狙い**：「魔窟の取引」「手札交換の儀」「手札一掃」などで手札の『魔窟』を捨て、自身の効果で特殊召喚・ドロー・除去を行う。「魔窟の龍帝ガルグラフ」が捨てられると相手のカードを1枚破壊。
- **強み**：手札から捨てるだけでカードを増やしながら盤面を作れる。相手の誘発（墓地へ捨てさせる効果）への耐性も高い。
- **弱み**：「魔窟の門番」使用後の召喚制限。罠が少ないので、防御はモンスターの数に頼る。

### ⑨ 機巧（参照：カラクリ）— Tier B（ベスト4入賞あり）
- **狙い**：攻撃対象に選ばれると表示形式が変わる『機巧』モンスターと、表示形式の変更で誘発する「機巧鋼将軍 型式零零X」（ドロー）、「機巧将軍 型式零零」（デッキから特殊召喚）で手札・盤面を増やす。
- **強み**：「機巧商人」のサーチ→同調召喚で手札を維持できる。「新月の秘本」や「機巧の隠し蔵」でも表示形式を変えられる。
- **弱み**：同調召喚に頼るので「雷獣王ボルガ」や「王政の圧制」が重い。

### ⑩ 夜鴉（参照：BF／墓地BF・旋風BF）— Tier B〜A
- **狙い**：「夜鴉の旋風」で召喚のたびにサーチしながら、手札から特殊召喚できる『夜鴉』を並べる。「夜鴉 大旗のヴァユ」の墓地効果で同調モンスターを出す。「夜鴉の鎧将」「夜天竜ノクス」で戦う。
- **強み**：旋風からの展開量と、ヴァユ・ゼフィ（回数制限なし）で墓地から再展開できる。
- **弱み**：単体の打点が低く、「大激流」「虚無の大穴」で崩れやすい。
- **型の違い**：旋風BFは「夜鴉の旋風」中心、墓地BFは「愚者の埋葬」と「ヴァユ」中心。本レシピは両方の要素を入れた汎用型。
