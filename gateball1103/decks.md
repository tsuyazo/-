## 1. データについて（重要）

- 目標は「1103ゲートボール直近100大会のベスト8」の集計だったが、今回の作業環境からは大会結果ページ（note・はてな・ガチまとめ・X等）を直接開けず、**検索結果の抜粋で読めた分だけ**を使っている。100大会分の上位8デッキを1件ずつ数えた集計にはなっていない。

## 2. 環境の構造

1. **罠の質と量がそのまま強さになる環境**。「奈落の落とし穴」「神の警告」「神の宣告」「激流葬」「聖なるバリア -ミラーフォース-」「次元幽閉」「強制脱出装置」がほぼ全デッキの共通パーツで、メインの3割前後が罠。
2. **特殊召喚の量で2つに分かれる**。
   - 少しだけ出して罠で守るデッキ：兎ラギア、代行天使、HERO、カラクリ。
   - 大量展開するデッキ：デブリダンディ（デブリ）、クイックダンディ、TGガジェット（TG）、六武衆、BF、暗黒界。
   - 前者は「増殖するG」「ライオウ」「王宮の弾圧」「大天使クリスティア」で後者を止めにいく。この噛み合いが環境の軸。
3. **ランク4のエクシーズ召喚が全デッキの共通の出口**。「No.39 希望皇ホープ」が攻撃を止める壁兼打点になる。兎ラギアは「エヴォルカイザー・ラギア」で召喚・魔法・罠を無効にでき、罠デッキとして一番強い形。
4. **後攻の捲りは「ブラック・ホール」「サイクロン」「魔導戦士 ブレイカー」「E・HERO エアーマン」**。制限カードを何枚引けるかで勝負が決まる面が大きい。
5. 先攻もドローできるので、先攻有利がかなり大きい。

## 3. 10デッキ解説

### ① 兎ラギア— Tier S
- **狙い**：「レスキューラビット」で同名の通常モンスター（恐竜）2体をデッキから出し、「エヴォルカイザー・ラギア」（召喚・魔法・罠を1回無効）か「No.39 希望皇ホープ」を立てる。あとは罠で守る。
- **強み**：手札1枚でエクシーズモンスターが出る。メインは罠の多いパーミッション型で、「ライオウ」「王宮の弾圧」「増殖するG」で展開デッキに強い。
- **弱み**：「野ウサギ」以外の初動が少ない。「奈落の落とし穴」「次元幽閉」でラグナレイジを除去されやすい。
- **主な動き**：野ウサギ召喚 → 除外してサーベラス×2 → ラグナレイジをエクシーズ召喚。

### ② 代行天使— Tier S
- **狙い**：「神秘の代行者 アース」→「創造の代行者 ヴィーナス」→「神聖なる球体」で数を並べ、「マスター・ヒュペリオン」の破壊効果（「天空の聖域」があれば1ターンに2回）で盤面を取る。墓地の天使族が4体になったら「大天使クリスティア」で特殊召喚を止める。
- **強み**：ソル・マギステルの継続的な除去と、アークリスタのロックが強い。
- **弱み**：LPを払う動きが多く、バーンや激流葬に弱い。墓地の天使族の数を調整する必要がある。
- **主な動き**（通常召喚は1ターンに1回なので、どちらか一方を召喚する）：
  - ウェヌスを召喚 → 500LPずつ払ってデッキからルミナを並べる → ウェヌスを除外してソル・マギステルを手札から特殊召喚。
  - 場にモンスターがいない時に「神の居城-ヴァルハラ」で手札のウェヌスを特殊召喚 → テラを通常召喚してソル・マギステル（聖庭がある時）かウェヌスをサーチ。
  - テラを召喚した場合、サーチしたウェヌスはそのターンには召喚できない（次のターン以降、または大広間で出す）。

### ③ HERO（アライブHERO・ピュアHERO）— Tier A
- **狙い**：「E-エマージェンシーコール」「ヒーローアライブ」でサーチし、「E・HERO エアーマン」で魔法・罠を割る。「ミラクル・フュージョン」から「E・HERO アブソルートZero」（離れると相手モンスター全破壊）や「E・HERO エスクリダオ」を出す。
- **強み**：サーチが厚く安定する。罠ビートで、後攻の捲りも得意。
- **弱み**：単体の打点が低めで、「ライオウ」にサーチを止められる。
- **主な動き**：ヒーローアライブ（LP半分）→ エアーマン特殊召喚、効果でHEROをサーチ → 2体目のHEROを召喚 → ミラクル・フュージョンでアブソルートZero。HEROが並んだ状態でエアーマンを出せば、その数だけ伏せカードを割れる。

### ④ TGガジェット— Tier A
- **狙い**：ギア人形（紅→琥珀→翠→紅…）が1枚ごとにサーチしてくるので手札が減らない。そこにTG（チューナー）を足し、レベル5〜8のシンクロ召喚で「TG ハイパー・ライブラリアン」のドローや「氷結界の龍 ブリューナク」の手札戻しにつなぐ。
- **強み**：手札が尽きにくく、罠が多いので長期戦に強い。（寒波亭では「TG代行天使」という混成型も準優勝している。）
- **弱み**：初動の打点が低い。「ライオウ」でサーチを止められる。
- **主な動き**：相手の場だけにモンスターがいる時に、先にストライカーを手札から特殊召喚 → 紅を通常召喚して琥珀をサーチ → 紅（4）＋ストライカー（2）でレベル6シンクロ（ブリュンガル）。紅を先に出すとストライカーの条件（自分の場にモンスターがいない）を満たせなくなる。

### ⑤ デブリダンディ— Tier A
- **狙い**：「デブリ・ドラゴン」「ジャンク・シンクロン」で墓地の植物を蘇生し、「ダンディライオン」のトークン、「グローアップ・バルブ」「スポーア」の自己再生を絡めてシンクロ召喚を連打する。「氷結界の龍 トリシューラ」「ブラック・ローズ・ドラゴン」が決め手。
- **強み**：1ターンでの展開量と、トリスカルの3枚除外が非常に強い。
- **弱み**：「増殖するG」「ライオウ」「王宮の弾圧」「大天使クリスティア」に止められる。
- **主な動き**：「おろかな埋葬」や「ワン・フォー・ワン」でダンディライオン・グローアップ・バルブを墓地へ → 綿毛トークン2体 → ジャンク・シンクロンを通常召喚して墓地の球根を蘇生 → シンクロ召喚を連打。終末の騎士とジャンク・シンクロンはどちらも通常召喚なので、1ターンに使えるのは片方だけ。

### ⑥ クイックダンディ（参照：クイックジャンド/クイックダンディ）— Tier A
- **狙い**：「クイック・シンクロン」（手札1枚を墓地へ送って特殊召喚できるレベル5チューナー）で植物を墓地へ送りつつシンクロ召喚する。「レベル・スティーラー」でレベルを調整する。
- **強み**：「チューナー」でデッキを掘れて初動が安定する。手札誘発（甲虫・ヴェール）を構えながら展開できる。
- **弱み**：クイック・シンクロンの素材制限があり、出せるシンクロモンスターが限られる。妨害への弱さはデブリ型と同じ。

### ⑦ 六武衆— Tier A
- **狙い**：「剛刃のキザシ」など手札から特殊召喚できるモンスターを並べ、「六武衆の結束」でドロー、「六武の門」でサーチ。「真六武衆-シエン」で魔法・罠を無効にする。
- **強み**：手札だけで展開できて爆発力がある。「六尺瓊勾玉」で破壊効果を防げる。
- **弱み**：「ブラック・ホール」「激流葬」が刺さる。手札誘発・パーミッションへの耐性が低い。
- **主な動き**：カゲトキを召喚し、効果で手札の影武者を特殊召喚 → キザシを手札から特殊召喚 → 結束にカウンター2 → 影武者（2）＋カゲトキ（3）で蒼月をシンクロ召喚。

### ⑧ 暗黒界— Tier B（寒波亭で優勝あり）
- **狙い**：「暗黒界の取引」「手札断殺」「手札抹殺」などで手札の「暗黒界」を捨て、自身の効果で特殊召喚・ドロー・除去を行う。「暗黒界の龍神 グラファ」が捨てられると相手のカードを1枚破壊。
- **強み**：手札から捨てるだけでカードを増やしながら盤面を作れる。相手の誘発（墓地へ捨てさせる効果）への耐性も高い。
- **弱み**：「暗黒界に続く結界通路」使用後の召喚制限。罠が少ないので、防御はモンスターの数に頼る。

### ⑨ カラクリ— Tier B（ベスト4入賞あり）
- **狙い**：攻撃対象に選ばれると表示形式が変わる「カラクリ」モンスターと、表示形式の変更で誘発する「カラクリ大将軍 無零怒」（ドロー）、「カラクリ将軍 無零」（デッキから特殊召喚）で手札・盤面を増やす。
- **強み**：「カラクリ商人」のサーチ→シンクロ召喚で手札を維持できる。「月の書」や「借カラクリ蔵」でも表示形式を変えられる。
- **弱み**：シンクロ召喚に頼るので「ライオウ」や「王宮の弾圧」が重い。

### ⑩ BF（墓地BF・旋風BF）— Tier B〜A
- **狙い**：「黒い旋風」で召喚のたびにサーチしながら、手札から特殊召喚できる「BF」を並べる。「BF-大旆のヴァーユ」の墓地効果でシンクロモンスターを出す。「BF-アーマード・ウィング」「ブラックフェザー・ドラゴン」で戦う。
- **強み**：旋風からの展開量と、ヴァユ・ゼフィ（回数制限なし）で墓地から再展開できる。
- **弱み**：単体の打点が低く、「激流葬」「ブラック・ホール」で崩れやすい。
- **型の違い**：旋風BFは「黒い旋風」中心、墓地BFは「おろかな埋葬」と「ヴァユ」中心。本レシピは両方の要素を入れた汎用型。
