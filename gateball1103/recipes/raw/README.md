## note画像の書き起こしについて（重要）

note のレシピはすべて**画像**（遊戯王ニューロンのデッキ画面のスクリーンショット）で、テキストのカードリストはない。そのため次の手順で目視で書き起こした:

1. 画像の各段のカード名部分を切り出して拡大し、文字を読む
2. 文字がつぶれている場合は、イラスト・レベル・属性・カード枠の色で特定する。他の高解像度の画像ではっきり読めた同じカードとも照合する
3. 書き起こした全232種のカード名を、公式DBのカード検索で**完全一致**することを確認（不一致0件）
4. 各段の合計が、画像見出しの「メインデッキ：N枚」などと一致することを確認（全11件一致）

`"uncertain": true` が付いたカードは、文字が読めずイラストなどから推定したもの。`"（判読不能）"` は、カードを特定できなかったもの（枚数は画像どおり）。該当するのは代行天使とTGガジェットの2件だけ。ほかの9件は、文字かイラストではっきり特定できた。

## recipes.json のフィールド

`archetype, title, event, date, placing, player, source_url, main, extra, side` は依頼どおり。追加したフィールド:
- `placing_confirmed` … 入賞記録がページで確認できたか（true/false）
- `image_url` … 書き起こし元の画像（note由来のみ）
- `source` … データの取り方（画像の書き起こし / DBページのテキスト抽出）
- `note` … 補足（低解像度、同じ画像の重複、日付の根拠など）
- カードごとの `uncertain` … 上記の要確認フラグ

`title` は、note 由来では画像の見出しの文字、DB 由来ではページの h1 の文字。`placing` の「（チーム）」は、キャプションにチーム戦と書かれていたもの。メインは全件 40〜45 枚、EX は 15 枚以下に収まっている。
