## decks.json の項目

- 指定の項目：archetype_key / date / event / result / url / main / extra / side / unreadable
- 追加した項目：
  - **period**：制限リストの期間。
    - 例：1103 は2011年3月制限、1009 は2010年9月制限。
    - 大会の日付が分かるものは大会の日付で決めた。それ以外は記事の日付で決めた。根拠は period_basis に書いた。
    - 2005年3月より前の3件は「不明」にした。
  - **environment**：period を文章にしたもの。
  - **note**：本文中の注記や、読み方の判断。
  - **selected_for_archetype**：アーキタイプごとに選んだリストの印。
  - **side_alt / side_label**：サイドが複数ある記事。
    - 神奈川版と東海版、愛知個人版と愛知チーム版とKnifeCS版、など。
- カード名：
  - cards.json にあるものは cards.json の name に合わせた。
  - 無いものは公式名（cdb の名前をNFKCで半角化したもの）にした。
- 枚数：本文に書かれたとおりにした。
  - 本人が 41〜45枚と書いたメインはそのまま。
  - サイドが13・14枚と書かれたものもそのまま。
- 記事にあるデッキの写真について：
  - 写真は、同じ記事にテキストで載っているリストの写真だった。
  - 画像にしか無いデッキリストは無かった。2010〜2011年のデッキ記事の画像を確認した。

## 1103のプレイで特に重要な知見（advice.json から抜粋）

- 1103の墓地BF
  - 警告は抜く。墓地BFとヒーロービートが多く、ライフが持たない。
  - カードガンナーは2枚。
  - 先攻はバックを1〜2枚伏せるだけで、初手にモンスターを出さない。
  - 奈落はゴドバのサクリファイス・エスケープで避けるか、仕掛けをワンテンポ早くする。
- 召喚時の優先権が無くなった（2011.03.19から）
  - 奈落が強くなった。
  - 天使（ヒュペリオン・裁き）が弱くなった。
- 伏せ除去が少ない環境
  - 罠の価値が上がる。
  - サイクロンより、トラスタ・七つ道具を使う。
  - お互いにサクリファイス・エスケープを持つ時は、少数の伏せで戦う。
- ジャンド：本人が1103で主に使ったデッキ。
  - デブリ・植物エンジン型にする。
  - トマト2、ガンナー、ハリケーン。
  - ライブラリアンが核。
  - サイド後はコンボ一辺倒にしない。
