# 1103環境 デッキ別 展開ルート・カード運用メモ（knowhow2）

前回の [knowhow](../knowhow/knowhow.md) より具体的な「手順」「カードごとの使い所」をまとめたもの。プログラム用のデータは [lines.json](lines.json)、参照したページは [sources.md](sources.md)。

- カード名は `data/cards.json` の `name` と同じ表記。本ゲームのデッキに無いカード（記事で使われているが本ゲーム未収録のもの）は lines.json には入れていない。
- 記事に書かれていない手順は推測で補っていない。見つからなかった項目は「見つからず」と書いた。
- 記事の多くは2022〜2026年のゲートボール（寒波亭ルール）向けで、MD（マスターデュエル）での記事は先攻ドローなし・王宮の弾圧なしの点が本ゲームと違う。

## 1. 兎ラギア（rabbit）

**方針**：下級1900〜2000打点のビートダウン。最速でライフを取り切る。迷ったら「召喚、攻撃」。過剰なケアはしない（ミラーフォースが初動で直撃するのは約9%）。[出典](https://note.com/brainy_roses651/n/n4071f0029842)、[出典](https://note.com/brainy_roses651/n/nd879411117ba)

### 展開ルート
1. **先攻ラビット→ラギア**（優先度9）：強欲で謙虚な壺があれば最初に使う → レスキューラビット召喚 → セイバーザウルス2体（ワーウルフはデッキに残す）→ エヴォルカイザー・ラギア → 魔法罠を全部伏せる。[出典](https://note.com/pkpkpkt/n/nf8a00dfe9275)
2. **奈落ケア**：手札にブレイカーとラビットがあれば、ブレイカーを先に出して奈落を踏ませ、次のターンにラビット。[出典](https://note.com/pkpkpkt/n/nf8a00dfe9275)
3. **ラビット→ワーウルフ2体→ランク4**：セイバーザウルスが足りない時や2枚目のラビット。ゴーズの守備表示が越えられない時はジェムナイト・パール、リバースモンスターにはイビリチュア・メロウガイスト。[出典](https://note.com/mame_nya/n/n424dbdc0e938)、[出典](https://note.com/horo1103/n/nc7cb4699b028)
4. **ラビット無しの先攻**：ライオウ（無ければバニラ）＋全伏せ。[出典](https://note.com/pkpkpkt/n/n1c6fe93fc98d)
5. **対リバースモンスター**：ラギアは反転召喚を止められないので出さない。聖槍を持っている＋（七つ道具セット／ラビット所持／死者蘇生と対象）のうち2つを満たす時だけ、2ターンで3体並べてショックルーラー。[出典](https://note.com/brainy_roses651/n/nd879411117ba)
6. **後攻**：伏せの上からラビットは通りにくい。サイクロン・ブレイカー・バニラで罠を踏ませてから殴る。[出典](https://note.com/horo1103/n/ncdc4cfe3f609)

### カードの使い所（抜粋）
- **ラギアの効果**：召喚・魔法罠の発動を無効（効果モンスターの効果・反転召喚は不可）。相手のリソースが尽きかけた時の強欲で謙虚な壺、カラクリ忍者 九壱九の召喚、暗黒界の起点の魔法などに使う。攻撃反応罠や早撃ちには使わない。[出典](https://note.com/horo1103/n/nca5499d8955f)、[出典](https://note.com/horo1103/n/n6dd33845024e)
- **神の警告**：シンクロ・エクシーズ・ゴーズに。アナザー・ネオスはデュアルスパークで逃げられる。誰に撃つかはセット時に決めておく。
- **強制脱出装置**：エクストラから出たモンスターに（例：ライオウに殴りかかるヴィーナス＋ガチガチのガチガチを戻す）。天使・暗黒界には効きにくい。[出典](https://note.com/igaemi/n/ndd624d91266f)
- **奈落**：ミラー・天使には重要、ガジェット・カラクリ・ジャンド・六武衆後攻では弱い。鳥獣族には撃たない（ゴッドバードアタック）。
- **次元幽閉**：アナザー・ネオスにはデュアルスパークでかわされるので撃たない。
- **七つ道具**：トップで引いたターンは動かずセットしてから動く。

### 先攻・後攻・伏せ
- 先攻：ラビット＞ライオウ＞バニラ、魔法罠は全伏せ。神の警告が無いからと伏せを絞らない（多伏せそのものがブラック・ローズ・ドラゴンへの圧）。
- ライコウ入りの相手には、最初は重要でない罠（サイクロン、ミラーフォース）を置いて割らせる。

### よくあるミス
過剰ケアで殴らない／七つ道具を引いたターンに動いて全体除去を食らう／リバース持ち相手にラギア／聖槍なしのショックルーラー／ラギア効果の早撃ち／1伏せにラビットで突っ込んで奈落／BFのカルートを忘れる、など（lines.json の mistakes）。

## 2. 代行天使（agent）

※本ゲームのレシピはTG入り（大天使クリスティア・神の居城－ヴァルハラ・シャインエルフ・朱光の宣告者は入っていない）。記事のうちそれらに依存する手順は lines.json に入れていない。

**方針**：ワンキルにはヴィーナスがほぼ必須。準備が整うまでTGと守り札でパーツを集め、溜めたリソースでワンキルへ。TGは戦闘破壊されても損しないので積極的に殴って削っておく。[出典](https://note.com/kind_daphne362/n/n77caac21a518)

### 展開ルート
1. **先攻アース→ヴィーナスをサーチ＋神の警告**（優先度8）。[出典](https://note.com/joshua1103/n/n6c297fdad49d)
2. **先攻ヴィーナス→球体3体**：先攻でヴィーナスがあれば基本出すという意見。ランク2は相手で選ぶ：暗黒界にはガチガチガンテツ、デブリには重ねずバラで置く、ラギア・ガジェット・カラクリ・ミラーにはガチガチは避ける（強制脱出装置で全てを失う）。[出典](https://note.com/kodaisukekane/n/n9056865c4306)、[出典](https://note.com/cacturne/n/n979ff641a8fd)
3. **後攻ストライカー＋ヴィーナス→ガチガチガンテツ＋ダイガスタ・フェニクス（＋TG ワーウルフ）**：ガチガチ・フェニクス2回・ヴィーナスで6700、3体目の球体に合わせたワーウルフで1ターンキル。[出典](https://note.com/modern_dietes85/n/n1e36e6beaead)
4. **アース＋ヴィーナス＋球体3体→フェニクス2体＋ヴィーナス**で7600。[出典](https://note.com/igaemi/n/n7ef8a22b022f)
5. **アース＋ヴィーナス→トリシューラ**（サイド後はブラック・ローズ・ドラゴンで球体を2つ残す）。[出典](https://note.com/cacturne/n/n979ff641a8fd)
6. **ストライカー＋ヴィーナス→トリシューラ**。[出典](https://note.com/modern_dietes85/n/n1e36e6beaead)
7. **ヴィーナスが奈落で除外された時**：破壊されたストライカーでワーウルフをサーチ → ジャンク・シンクロンでストライカー蘇生 → ワーウルフ特殊召喚 → 虚空海竜リヴァイエールでヴィーナス帰還。[出典](https://note.com/kind_daphne362/n/n77caac21a518)
8. **アースを守れない時**：クリッターをセット → 次のターンにアース＋クリッターでTG ハイパー・ライブラリアン。[出典](https://note.com/cacturne/n/n979ff641a8fd)

### カードの使い所（抜粋）
- **マスター・ヒュペリオン**：妨害を必ず踏むので温存しない。ガジェット相手は聖槍なしでも投げて伏せを割る。[出典](https://note.com/kodaisukekane/n/n9056865c4306)
- **サイクロン**：王宮の弾圧用に温存（七つ道具の可能性があるのでサイクロンを優先して残す）。暗黒界の門は必ず割る。HERO相手は未来融合を割るために伏せる。[出典](https://note.com/cacturne/n/n979ff641a8fd)
- **神の警告**：アースを守る、キル時のゴーズ・トラゴエディア封じ、TGを狙うトリシューラ・メロウガイストから守る。ライフが重く後攻・ガジェット相手では弱い。
- **激流葬**：ライオウ・ローチ・大型。ヴィーナスに奈落が来たら除外を避けて自分ごと流すことも。
- **精神操作**：ミラーで相手のヴィーナスを奪ってトリシューラ。
- **神聖なる球体**：手札に来ても壁として無駄に出さない。

### 先攻・後攻・伏せ
- 先攻はアース＋警告。警告なしのガン伏せはしない。ダスト・シュートがある環境では手札を3枚以下に（ドロー直後に優先権で魔法を使う手もある）。
- 後攻はストライカーから。ガジェット相手はつり天井があるので並べすぎない。具体的な伏せ枚数の数値は見つからず。
